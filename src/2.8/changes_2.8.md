## Новые файлы (33)

### 1. Модуль-загрузчик `mod_dynmap.class`
- Регистрирует горячую клавишу **Dynmap** (по умолчанию клавиша **N**, код 49) через ModLoader (`ama.a(alz, aat, false)`).
- По нажатию открывает главный экран карты `dyn`, повторное нажатие — закрывает.
- Содержит `Ab(String)` — открытие URL Dynmap в браузере (Chrome / Firefox / Edge) с автоопределением ОС и режимом инкогнито.

### 2. Главный экран карты `dyn.class`
- Оверлейная карта поверх игры: масштаб, панорамирование (Shift/Alt + колесо мыши, сдвиг PX), подгрузка тайлов по HTTP из URL Dynmap.
- Отображение маркеров, станций и линий метро, улиц, зданий, жителей и мэров города.
- Режимы: город (улицы/здания/жители), метро, маркеры.
- Настраиваемые горячие клавиши (через `hotkeys`).
- Вложенные классы: `dyn$1`, `dyn$2` (анонимные обработчики).

### 3. Менеджер данных `mrk.class` и модели
- `mrk` — загрузка/сохранение данных в `rumo.json`, миграция из `markers.json`, импорт через JSON, связка метро (`mt`) и города (`dyn`).
- `mrk$Data`, `mrk$Entry`, `mrk$1`, `mrk$2`, `mrk$3` — структуры данных и TypeToken-обёртки для Gson.
- `mt`, `mt$Station`, `mt$Line` — система метро: станции (координаты, название, цвет) и линии.
- `Building`, `Building$Resident`, `Citizen`, `Street` — модели данных города.
- `net/minecraft/mods/RuMO/*` — дублирующие копии моделей в отдельном пакете.

### 4. Экраны интерфейса
- `bld` — редактор здания (тип, имя, владелец, строители, жители, номер дома, адрес, инфо).
- `bli` — список зданий (поиск, постраничная навигация, Go/Edit/Delete).
- `cli` — список и редактор жителей и мэров.
- `sli` — список улиц.
- `str` — ввод названия улицы.
- `mks` — редактор маркера (имя, описание, X/Z, цвет, стиль).
- `mkl` — список маркеров.
- `mte` — редактор станции метро (X/Z, название, линии).
- `mtl` — список станций метро (поиск, Go/Edit/Delete).
- `dyb` — настройки Dynmap (импорт, сброс, переключатель метро).
- `coord` — ввод координат X/Z для навигации.
- `url` — редактирование URL Dynmap-сервера.
- `hotkeys` — настройка горячих клавиш (группы Basic / Metro / City).

## Изменения в существующих файлах (4)

### `aar.class` — GameSettings
Добавлены поля и логика Dynmap:
- `Wz` (`aat`, «key.dynmap», клавиша 49/M) — новая клавиша, попадает в список клавиш через ModLoader при инициализации.
- `Wx` (`String`) — URL Dynmap-сервера, по умолчанию `https://map.rubeta.net/`.
- `ju()` (загрузка опций) — читает строку `dynmapUrl:` из `options.txt` (URL-декодирование) и применяет её в `Wx` при наличии `://`.
- `jv()` (сохранение опций) — записывает строку `dynmapUrl:` в `options.txt`.

## Резюме
Модификация переносит в целевой клиент полноценный модуль RuMO: оверлейная карта с тайлами Dynmap, маркеры, метро, городская разметка (улицы/здания/жители/мэры), настраиваемые горячие клавиши, координатная навигация, редакторы URL и интеграция с браузером. Все классы мода адаптированы под карту обфускации целевого клиента.
