# RuMO
Client mod that allows you to open dynmap in game. Made specially for Rubeta - a custom modded server on version b1.7.3

---

_Еще с апреля я пытаюсь интегрировать динамическую карту прямо в игру
и относительно недавно мне это удалось и давольно успешно:
Я смог модифицировать клиент так, чтобы пользователи (игроки) могли
открывать динамическую карту прямо в игре. К сожалению, перенести метки
с сайта не удалось, поэтому я реализовал новую систему разметки._

### Разметка включает в себя:
- маркеры (аналоги меток с сайта. можно выбирать цвет и важность метки (город, поселок, точка))
- система метро (разметка метро со станциями, улучшенная версия того, что когда-то давно было в карте на сайте)
- система городской разметки (метки зданий, улицы, жители города, мэр, короче, фигня для шизов)))

### Также я приделал пару удобных функций:
- удобное перемещение по карте (вводишь координаты и камера перемещается)
- списки меток и удобный поиск по ним
- быстрое ЛС игроку (по приколу, лол)
- возможность скрытия меток
- экспорт/импорт меток
